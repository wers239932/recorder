# Настройка аутентификации ESP32-C6

## Файл конфигурации на плате

Файл `/spiffs/auth_config.json` на плате ESP32-C6 должен содержать:

```json
{
  "login": "0006",
  "password": "esp32_device_secret_key",
  "server_url": "http://192.168.1.12:8080/api/v1/device/auth/login",
  "upload_url": "http://192.168.1.12:8080/api/v1/data/upload",
  "command_url": "http://192.168.1.12:8080/api/v1/device/command"
}
```

## Поля конфигурации

| Поле | Описание |
|------|----------|
| `login` | Уникальный идентификатор устройства (например, MAC-адрес или серийный номер) |
| `password` | Секретный ключ устройства (используется для генерации password_hash через SHA-256) |
| `server_url` | Endpoint для аутентификации устройства |
| `upload_url` | Endpoint для загрузки записей |
| `command_url` | Endpoint для получения команд от сервера |

## Как обновить конфигурацию

### Вариант 1: Через SPIFFS

1. Подключитесь к плате через последовательный порт
2. Загрузите файл `auth_config.json` в SPIFFS:
   ```bash
   pio run --target uploadfs
   ```

### Вариант 2: Автоматическое создание

При первом запуске прошивка создаст файл-шаблон `/spiffs/auth_config.json` с дефолтными значениями. Отредактируйте его через последовательный порт или пересоздайте через Вариант 1.

## Динамическая регистрация

При первом подключении устройство автоматически регистрируется на сервере:
1. Плата отправляет `login` и `password_hash` (SHA-256 от `password`)
2. Сервер создаёт новую запись в таблице `devices`
3. Сервер возвращает Bearer-токен для последующих запросов

## Привязка устройства к пользователю

Для привязки устройства к пользователю Telegram:
1. Пользователь входит в бота
2. Отправляет команду `/link_device 0006` (логин устройства)
3. Сервер связывает устройство с `user_id` пользователя
4. Записи с устройства появляются в списке записей пользователя
