# Telegram Bot — Расшифровка и Суммаризация

## ✅ Кнопки уже интегрированы!

Бот поддерживает кнопки:
- 📄 **Текстовая расшифровка** — расшифровка аудио в текст
- 📋 **Краткое содержание** — суммаризация текста

---

## Быстрый старт

### 1. Настройка переменных окружения

Создайте файл `.env` в папке `telegram_bot/`:

```bash
cd telegram_bot
cat > .env << EOF
BOT_TOKEN=your_bot_token_here
SERVER_URL=http://localhost:8080
EOF
```

**Получение токена бота:**
1. Откройте @BotFather в Telegram
2. Создайте нового бота: `/newbot`
3. Скопируйте токен (выглядит как `123456:ABC-DEF1234...`)
4. Вставьте в `.env`

### 2. Установка зависимостей

```bash
cd telegram_bot

# Создание виртуального окружения
python3 -m venv venv
source venv/bin/activate  # На macOS/Linux

# Установка зависимостей
pip install -r requirements.txt
```

### 3. Запуск бота

```bash
# Виртуальное окружение должно быть активно
python bot.py
```

## Сценарий работы

### Расшифровка аудио:

1. Пользователь отправляет аудио через ESP32-C6
2. В боте: `/recordings` → выбор записи
3. Нажимает: **📄 Текстовая расшифровка**
4. Бот вызывает: `POST /api/v1/bot/recordings/{id}/transcribe`
5. Ожидает 5-30 секунд
6. Показывает текст расшифровки

### Суммаризация:

1. Пользователь отправляет аудио через ESP32-C6
2. В боте: `/recordings` → выбор записи
3. Нажимает: **📋 Краткое содержание**
4. Бот вызывает: `POST /api/v1/bot/recordings/{id}/summarize`
5. Ожидает результат
6. Показывает краткую выжимку

## Возможные проблемы

### Бот не запускается

**Ошибка:** `No module named 'telegram'`

**Решение:**
```bash
cd telegram_bot
source venv/bin/activate
pip install -r requirements.txt
```

### Бот не подключается к серверу

**Ошибка:** `Connection refused`

**Проверка:**
```bash
# Сервер запущен?
curl http://localhost:8080/api/v1/health

# Правильный SERVER_URL в .env?
cat .env
```

### Расшифровка не работает

**Ошибка:** `Сервис расшифровки временно недоступен`

**Проверка:**
```bash
# ASR-сервис запущен?
curl http://localhost:8000/health

# Зеркало HuggingFace работает?
curl -I https://hf-mirror.com
```

### Суммаризация не работает

**Ошибка:** `Сервис суммаризации временно недоступен`

**Причина:** Требуется `OPENAI_API_KEY`

**Решение:**
1. Получить токен на https://api.vsellm.ru
2. Настроить Summarizer сервис
3. Запустить на порту 8081

## Интеграция с ESP32-C6

Устройство использует те же логин/пароль, что и бот:

1. На устройстве: `login = "test"`, `password = "password123"`
2. В боте: `/register` → логин: `test`, пароль: `password123`
3. Устройство автоматически привязывается к пользователю
4. Записи с устройства отображаются в `/recordings`
