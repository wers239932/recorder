# Инструкция по загрузке auth_config.json на ESP32-C6

## Файл конфигурации

Файл `data/spiffs/auth_config.json` содержит настройки аутентификации для платы ESP32-C6.

## Загрузка на плату

### Способ 1: Через PlatformIO (рекомендуется)

```bash
cd /Users/ki.a.kuznetsov/IdeaProjects/recorder

# Загрузить файловую систему SPIFFS
pio run --target uploadfs
```

После загрузки перезагрузите плату и проверьте логи:
```bash
pio device monitor
```

### Способ 2: Через последовательный порт

1. Подключитесь к плате через последовательный порт
2. Отправьте содержимое файла `auth_config.json` в файловую систему

## Проверка конфигурации

После загрузки проверьте логи платы:
```
I (1234) AUTH: Auth endpoints: login=0006 upload=http://192.168.1.12:8080/api/v1/data/upload command=http://192.168.1.12:8080/api/v1/device/command
```

## Параметры конфигурации

| Параметр | Значение | Описание |
|----------|----------|----------|
| `login` | `0006` | Уникальный идентификатор устройства (MAC-адрес) |
| `password` | `esp32_device_secret_key` | Секретный ключ для аутентификации |
| `server_url` | `http://192.168.1.12:8080/api/v1/device/auth/login` | Endpoint аутентификации |
| `upload_url` | `http://192.168.1.12:8080/api/v1/data/upload` | Endpoint загрузки записей |
| `command_url` | `http://192.168.1.12:8080/api/v1/device/command` | Endpoint получения команд |

## Динамическая регистрация

При первом подключении устройство автоматически регистрируется на сервере:
1. Плата отправляет POST запрос с `login` и `password_hash` (SHA-256)
2. Сервер создаёт запись в таблице `devices`
3. Сервер возвращает Bearer-токен (срок действия: 24 часа)
4. Токен используется для загрузки записей

## Привязка к пользователю

Для привязки устройства к пользователю Telegram:
1. Пользователь входит в бота (`/login`)
2. Отправляет команду `/link_device 0006`
3. Сервер связывает устройство с `user_id` пользователя
4. Записи с устройства появляются в `/bot/recordings`
